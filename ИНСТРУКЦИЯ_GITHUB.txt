╔══════════════════════════════════════════════════════════════╗
║     ПОШАГОВАЯ ИНСТРУКЦИЯ: GitHub Actions (для новичков)      ║
╚══════════════════════════════════════════════════════════════╝

╔═══════════════════════════════════════════════╗
║  ШАГ 1: Регистрация на GitHub                 ║
╠═══════════════════════════════════════════════╣
║                                               ║
║  1. Откройте:  https://github.com             ║
║                                               ║
║  2. Нажмите:   "Sign up"                      ║
║                                               ║
║  3. Введите:   - Email                        ║
║                - Пароль                       ║
║                - Username (придумайте)        ║
║                                               ║
║  4. Подтвердите email (письмо придёт на почту)║
║                                               ║
║  ✅ Готово! Вы зарегистрированы.              ║
║                                               ║
╚═══════════════════════════════════════════════╝

╔═══════════════════════════════════════════════╗
║  ШАГ 2: Создание репозитория                  ║
╠═══════════════════════════════════════════════╣
║                                               ║
║  1. Нажмите зелёную кнопку:  "+ New"         ║
║     (в правом верхнем углу)                   ║
║                                               ║
║  2. Заполните:                                ║
║     - Repository name:  StockTracker          ║
║     - Description:      Моё приложение        ║
║     - ✅ Public (галочка)                     ║
║     - ❌ НЕ ставьте галочку на "Add README"   ║
║                                               ║
║  3. Нажмите:  "Create repository"             ║
║                                               ║
║  ✅ Репозиторий создан!                       ║
║                                               ║
╚═══════════════════════════════════════════════╝

╔═══════════════════════════════════════════════╗
║  ШАГ 3: Загрузка файлов                       ║
╠═══════════════════════════════════════════════╣
║                                               ║
║  1. На странице репозитория нажмите:          ║
║     "uploading an existing file"              ║
║     (ссылка под Quick Setup)                  ║
║                                               ║
║  2. Распакуйте архив StockTracker.zip         ║
║     на вашем компьютере                       ║
║                                               ║
║  3. Перетащите ВСЕ файлы и папки              ║
║     в окно браузера на GitHub                 ║
║                                               ║
║     ⚠️ ВАЖНО: Должны быть загружены:          ║
║        - build.gradle                         ║
║        - settings.gradle                      ║
║        - gradle.properties                    ║
║        - gradlew                              ║
║        - папка app/ (целиком)                 ║
║        - папка gradle/ (целиком)              ║
║        - папка .github/ (целиком)             ║
║                                               ║
║  4. Прокрутите вниз, нажмите:                 ║
║     "Commit changes"                          ║
║                                               ║
║  ✅ Файлы загружены!                          ║
║                                               ║
╚═══════════════════════════════════════════════╝

╔═══════════════════════════════════════════════╗
║  ШАГ 4: Автоматическая сборка APK             ║
╠═══════════════════════════════════════════════╣
║                                               ║
║  ⚡ Сборка начнётся АВТОМАТИЧЕСКИ!            ║
║                                               ║
║  1. Перейдите во вкладку:  "Actions"          ║
║     (вверху страницы репозитория)             ║
║                                               ║
║  2. Вы увидите:  "Build APK" workflow         ║
║     Статус: 🟡 Жёлтый кружок = идёт сборка    ║
║               🟢 Зелёная галочка = готово!    ║
║               🔴 Красный крестик = ошибка     ║
║                                               ║
║  3. Подождите 5-10 минут                      ║
║     (можно обновлять страницу F5)             ║
║                                               ║
║  ✅ Сборка завершена!                         ║
║                                               ║
╚═══════════════════════════════════════════════╝

╔═══════════════════════════════════════════════╗
║  ШАГ 5: Скачивание APK                        ║
╠═══════════════════════════════════════════════╣
║                                               ║
║  1. Нажмите на завершённый workflow           ║
║     (зелёная галочка)                         ║
║                                               ║
║  2. Прокрутите вниз до раздела:               ║
║     "Artifacts"                               ║
║                                               ║
║  3. Вы увидите два файла:                     ║
║     📦 StockTracker-debug    ← для теста      ║
║     📦 StockTracker-release  ← для публикации ║
║                                               ║
║  4. Нажмите на нужный → скачается ZIP         ║
║                                               ║
║  5. Распакуйте ZIP → получите app-debug.apk   ║
║                                               ║
║  ✅ APK готов!                                ║
║                                               ║
╚═══════════════════════════════════════════════╝

╔═══════════════════════════════════════════════╗
║  ШАГ 6: Установка на телефон                  ║
╠═══════════════════════════════════════════════╣
║                                               ║
║  1. Перекиньте APK на телефон:                ║
║     - через USB кабель                        ║
║     - через Telegram (Saved Messages)         ║
║     - через Google Drive                      ║
║     - через Bluetooth                         ║
║                                               ║
║  2. На телефоне откройте APK                  ║
║                                               ║
║  3. Разрешите установку:                      ║
║     "Настройки → Безопасность →               ║
║      Неизвестные источники → Разрешить"       ║
║                                               ║
║  4. Нажмите "Установить"                      ║
║                                               ║
║  ✅ Приложение установлено!                   ║
║                                               ║
╚═══════════════════════════════════════════════╝
