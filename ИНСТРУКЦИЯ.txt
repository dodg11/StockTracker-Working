ВАРИАНТ 1: REPLIT (Самый простой - 5 минут)
═══════════════════════════════════════════════════════════════

Шаг 1: Откройте https://replit.com и зарегистрируйтесь

Шаг 2: Нажмите "+ Create Repl"
        - Template: выберите "Android" или "Java"
        - Name: StockTracker
        - Нажмите "Create Repl"

Шаг 3: Загрузите файлы
        - Нажмите на "Files" слева
        - Перетащите все файлы из папки StockTracker
        - Или загрузите архив StockTracker.zip и распакуйте

Шаг 4: Откройте Shell (вкладка снизу) и введите:
        chmod +x gradlew
        ./gradlew assembleDebug

Шаг 5: Скачайте APK
        - Перейдите в папку app/build/outputs/apk/debug/
        - Нажмите на app-debug.apk → Download


ВАРИАНТ 2: GITHUB ACTIONS (Автоматический - 10 минут)
═══════════════════════════════════════════════════════════════

Шаг 1: Откройте https://github.com и зарегистрируйтесь

Шаг 2: Создайте репозиторий
        - Нажмите "+" → "New repository"
        - Name: StockTracker
        - Выберите "Public"
        - Нажмите "Create repository"

Шаг 3: Загрузите файлы
        - Нажмите "uploading an existing file"
        - Перетащите все файлы из папки StockTracker
        - Нажмите "Commit changes"

Шаг 4: Сборка запустится автоматически!
        - Перейдите во вкладку "Actions"
        - Дождитесь зелёной галочки ✅
        - Нажмите на workflow → Artifacts → Download


ВАРИАНТ 3: CODEMAGIC (Профессиональный - 7 минут)
═══════════════════════════════════════════════════════════════

Шаг 1: Откройте https://codemagic.io и зарегистрируйтесь через GitHub

Шаг 2: Add application → выберите свой репозиторий StockTracker

Шаг 3: Start new build → выберите "Android"

Шаг 4: Скачайте APK после сборки


ВАРИАНТ 4: APPVET (Онлайн без регистрации)
═══════════════════════════════════════════════════════════════

⚠️ Этот вариант НЕ подходит для сборки, только для тестирования готовых APK


РЕКОМЕНДАЦИЯ
═══════════════════════════════════════════════════════════════

Для новичка лучше всего подходит ВАРИАНТ 2 (GitHub Actions):
- Не нужно ничего устанавливать
- Не нужно знать команды
- Просто перетащить файлы мышкой
- APK соберётся автоматически
